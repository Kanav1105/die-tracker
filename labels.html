Die Tracker — printable labels

Code 128. Print at 100% scale, do not "fit to page" or the bars distort and stop scanning. Machine labels: laminate and fix to the machine at eye height. Die labels below are for the pilot only; production die tags should be laser-etched stainless plates so they survive heat treatment.

Test before laminating: print one page, scan each code with the app, confirm it resolves. If a code reads as text but the app says "not recognised", the code does not match the database.
